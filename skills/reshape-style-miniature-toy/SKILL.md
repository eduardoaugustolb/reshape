# Miniature and toy modeling

Use [ReShape](../reshape/SKILL.md) for evidence-based approval and [the styles overview](../reshape-styles/SKILL.md) for mixed briefs.

## Visual references

- [Kenney Toy Car Kit visual sheet](https://kenney.nl/assets/toy-car-kit). Study chunky silhouettes and readable part separation at small scale.
- [Good Smile scale figure and miniature gallery](https://special.goodsmile.info/miku10th/en/). Compare feature emphasis and accessory thickness across formats.

Use these examples to study visual decisions. Use the user's own target for likeness, dimensions, and design requirements.

## Modeling pass

Set the final scale and preserve only details that read at that scale. Block supports, part splits, and clearances from the design. For a printable or assembled asset, use the specified manufacturing process and interface dimensions.

## Approval checks

Review at actual display size, then close up around supports and joins. When fabrication is requested, check thickness, clearances, closure, and silhouette at final scale.

Reject and correct these failures before approval. Fragile or unreadable features at intended scale, unexplained seams, and parts that cannot meet the specified manufacturing requirements. Record any remaining issue as partial delivery with a named view and cause.
