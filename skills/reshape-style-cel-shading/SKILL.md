# Cel-shaded rendering for 3D models

Use [ReShape](../reshape/SKILL.md) for evidence-based approval and [the styles overview](../reshape-estilos/SKILL.md) for mixed briefs.

## Visual references

- [Blender Manual Toon BSDF image example](https://docs.blender.org/manual/en/3.0/render/shader_nodes/shader/toon.html). Use the rendered example to isolate lighting-band behavior; use the docs for your installed version when configuring nodes.
- [DillonGoo Studios 3D anime reel](https://www.youtube.com/watch?v=cRzE-0P10_c). Study continuity of facial shadow shapes and outline readability in motion.

Use these examples to study visual decisions. Use the user's own target for likeness, dimensions, and design requirements.

## Modeling pass

Model forms that remain readable under neutral material. Specify the shadow-band palette, outline weight, and where lines should appear. Use shape or normal controls where needed and confirm how the target render or export handles the shading.

## Approval checks

Sweep the camera and key light across the intended range. Check band changes around face, joints, overlaps, and seams. Inspect outlines and shadow boundaries at output size and in animation.

Reject and correct these failures before approval. Shadow-band popping, doubled contours, lines crossing the wrong surfaces, or a shader concealing failed geometry. Record any remaining issue as partial delivery with a named view and cause.
