# Human anatomy for 3D modeling

Start with the general skill for the full figure or integrated region. Open a regional skill when sculpting or investigating a local defect. Apply integration criteria to the full asset and regional criteria to close-ups.

This catalog covers surface anatomy and visible oral structures. Each skill cites sources and distinguishes documented anatomy from practical sculpting and review criteria.
