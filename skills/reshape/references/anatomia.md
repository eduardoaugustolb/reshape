# Anatomia humana para modelagem 3D

Para a figura inteira ou uma região integrada, comece pela skill geral. Para esculpir ou investigar um defeito localizado, abra a skill específica. Aplique os critérios de integração no modelo completo e os critérios locais nas vistas de detalhe.

O catálogo cobre anatomia de superfície para modelagem externa, com dentes e língua quando a boca estiver visível. Cada skill identifica as fontes e distingue anatomia documentada de critérios práticos de escultura e revisão.
